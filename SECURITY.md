# Security Policy

## Supported Versions

Currently, only the latest version of StoryForge AI is supported with security updates.

| Version | Supported |
|---------|-----------|
| 1.0.x | ✅ |
| < 1.0 | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead:

- Describe the vulnerability clearly.
- Include steps to reproduce the issue.
- Explain the potential impact.
- Provide screenshots or logs if applicable.

The report will be reviewed as soon as possible.

---

## Scope

Security reports may include:

- Authentication issues
- API key exposure
- XSS vulnerabilities
- Injection attacks
- Dependency vulnerabilities
- Sensitive data exposure

---

## Response Process

Security reports will be:

1. Reviewed.
2. Verified.
3. Fixed.
4. Released in a future update.

Responsible disclosure is appreciated.
