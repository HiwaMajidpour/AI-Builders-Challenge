# User Stories

## Visitor

- As a visitor, I want to describe my creative idea in natural language.
- As a visitor, I want to receive AI-generated suggestions.
- As a visitor, I want AI to help improve my idea.
- As a visitor, I want to create moodboards.
- As a visitor, I want AI to generate a project roadmap.
- As a visitor, I want AI to recommend creative assets.
- As a visitor, I want to save my creative projects.
- As a visitor, I want to export my project as PDF.
- As a visitor, I want to collaborate with teammates.

---

## Designer

- Generate UI ideas.
- Generate color palettes.
- Generate typography recommendations.
- Create design systems.

---

## Story Creator

- Generate story structure.
- Improve storytelling.
- Generate characters.
- Generate dialogue.

---

## Team

- Share projects.
- Comment on ideas.
- Track revisions.
- Collaborate in real time.

---

## Administrator

- Manage users.
- Monitor AI usage.
- Review analytics.
- Manage project categories.
