# IBM Bob Usage

> **Project:** AI Creative Studio  
> **Challenge:** IBM AI Builders Challenge 2026  
> **Primary Development Tool:** IBM Bob  
> **AI Provider:** Google Gemini  
> **Original AI Integration:** IBM Granite / IBM watsonx.ai  
> **Status:** Final Submission Documentation

---

# Overview

IBM Bob was used as the primary AI-assisted development tool throughout the software development lifecycle of AI Creative Studio.

The project was developed as part of the **IBM AI Builders Challenge 2026**, where IBM Bob is required as the primary development tool for building the project.

AI Creative Studio uses artificial intelligence as a core functional component of the application. The application was originally developed with IBM Granite as part of the project's IBM AI integration strategy. After the available IBM trial credits were exhausted during development, the AI inference layer was migrated to Google Gemini to allow continued development and product demonstration.

This change affected the AI inference provider but did not change the role of IBM Bob as the primary development tool used throughout the project development process.

---

# Role of IBM Bob

IBM Bob was used as an AI-assisted development partner across multiple stages of the software development lifecycle.

- Project planning
- Architecture design
- Feature development
- React component development
- AI service development
- Prompt engineering
- Debugging
- Code improvement
- Documentation
- Final review and optimization

IBM Bob was used to accelerate development while the final implementation, testing, architectural decisions, and project direction remained under human oversight.
