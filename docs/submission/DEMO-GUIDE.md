# Overview

This guide describes the official product demonstration of **AI Creative Studio** for the IBM AI Builders Challenge 2026.

The demonstration presents an end-to-end content creation workflow, showing how a user moves from the landing page to project creation, AI-assisted content generation, content refinement, and project management.

The application was originally developed using IBM Granite Foundation Models during the IBM AI Builders Challenge. After the available IBM trial credits were exhausted, the current demonstration uses Google Gemini while preserving the same enterprise AI workflow and application architecture.

The demonstration is designed to remain within the challenge's three-minute limit.

## Step 5 — AI Content Generation

**Duration:** 40–50 seconds

Navigate to AI Studio.

Enter a prompt such as:

```

```

Choose:

- Content Type
- Tone
- Length

Generate the content.

### Key Message

The application validates the prompt, sends it to the AI provider, and displays the generated result for user review.
