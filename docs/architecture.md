# CreativeMind AI Architecture

## Project Overview

CreativeMind AI is an AI-powered creative assistant designed to help creators generate ideas, stories, video scripts, and social media content faster and more effectively.

## Problem Statement

Content creators often spend significant time brainstorming ideas, writing scripts, and planning creative content. Existing tools focus mainly on text generation rather than acting as true creative partners.

## Solution

CreativeMind AI leverages IBM Granite models to assist creators throughout the creative process by generating ideas, stories, scripts, and content plans.

## Core Features

### Idea Generator

Generate creative content ideas from a topic.

### Story Generator

Generate complete stories based on user prompts.

### Video Script Generator

Generate structured video scripts.

### Social Media Content Generator

Generate captions, hashtags, and calls-to-action.

## Technology Stack

Frontend:

* React
* Vite
* Tailwind CSS

Backend:

* Node.js
* Express

AI:

* IBM Granite
* IBM Bob

## Architecture

Frontend → Backend → IBM Granite → AI Response
