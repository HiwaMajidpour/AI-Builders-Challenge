# Overview

This directory contains the AI Engineering documentation for AI Creative Studio.

The purpose of this documentation is to explain how Artificial Intelligence is integrated into the application, how prompts are designed and evaluated, how model quality is measured, and how future AI capabilities will evolve within an enterprise architecture.

Unlike general software documentation, these documents focus specifically on AI system engineering.

The AI engineering documentation aims to:
