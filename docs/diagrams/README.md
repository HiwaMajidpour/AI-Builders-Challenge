# Overview

This directory contains all enterprise architecture diagrams for **AI Creative Studio**.

The diagrams provide a visual representation of the system architecture, component relationships, AI workflows, infrastructure, deployment strategy, data model, and user interaction.

All diagrams have been created using **Draw.io** and exported as high-quality **PNG** and **SVG** assets for documentation and presentations.
